Esta página resume los **tokens visuales** y los **componentes base** del sistema de diseño inspirado en [eaship.io](https://eaship.io).

Es útil como referencia rápida para diseñadores, desarrolladores y agentes de IA.

## Espaciado y sombra

El sistema usa una escala base de **8 px** para espaciados:

- `xs`: 4 px
- `sm`: 8 px
- `md`: 16 px
- `lg`: 24 px
- `xl`: 32 px

Sombra principal:

```
4px 4px 10px 0px rgba(0, 0, 0, 0.1)
```
